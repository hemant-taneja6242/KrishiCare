## 🛠️ Simplified 4-Day Stack

```
Frontend:  React + Vite (single app, two routes: /farmer and /admin)
Backend:   FastAPI (Python) — one service handles everything
AI Model:  Pre-trained PlantVillage model from HuggingFace (no training!)
Advisory:  Gemini 1.5 Flash API (free tier, instant setup)
DB:        SQLite (via SQLAlchemy) — zero setup
Map:       Leaflet.js + react-leaflet
Charts:    Recharts
Weather:   OpenWeatherMap free API
Auth:      Demo login (hardcoded roles: farmer / expert / admin)
Hosting:   Run locally, show on laptop
```

## ⚠️ Risk Mitigations

| Risk | Mitigation |
|---|---|
| HuggingFace model too slow | Pre-download & run locally. Use CPU-only mode. |
| Gemini API rate limit | Cache advisory responses in SQLite by disease name |
| Map looks empty | Pre-seed 10 realistic hotspot markers in DB |
| Internet down at venue | Run everything locally. Mock weather data as fallback. |
| Model gives wrong result | Pre-select demo images that model classifies correctly |
